# District boundaries

`rwanda_districts.geojson`: 30 Rwandan districts (ADM2), simplified, coordinates rounded to 3 decimals
(about 100 m), attributes reduced to the district name.

- **Source:** geoBoundaries gbOpen, release RWA-ADM2-39286606 (boundary year 2012, source data from
  Open Data Rwanda / NISR, updated 2023-01-19). https://www.geoboundaries.org
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0).
- **Cite:** Runfola, D. et al. (2020) geoBoundaries: A global database of political administrative
  boundaries. PLoS ONE 15(4): e0231866.
- **Changes:** simplified geometry (geoBoundaries `_simplified` file) and precision reduced; names unchanged.
  These boundaries predate any later administrative changes and are for display only.
